FEATURES

Discover the unique features that make Space Type an exciting typing adventure.

Difficulty & Speed Scaling

The game features a progressive difficulty curve. As your score increases, the velocity of falling asteroids accelerates. This ensures the game remains challenging regardless of your typing speed.

Data-Based Word Categories

The game uses an external data system that loads word lists from structured files. Players can select categories such as Animals, Fruits, Technology, Vegetables, and Countries.

Character Selection

Players can choose from unique astronaut identities such as Z3D, Luna, Matrix, Miller, and Draven before starting the game.

Power-Up Word Types

The game spawns four distinct entity types based on random probability; a Normal entity increases the score by one point, a Bonus (Green) entity adds one life, a Trap (Red) entity deducts one life, and a Slow (Blue) entity activates "Slow Mode".

Precision Safe-Area Rendering

The game includes UI safeguards that ensure smooth and readable gameplay. Horizontal padding keeps words within screen bounds, preventing them from rendering off-screen, while vertical clipping ensures words spawn properly below the HUD and interact correctly with the input system.

Hybrid Control System

Navigate the game using a mix of Mouse and Keyboard. Use the mouse for menu selections and character switching, and the keyboard for high-speed typing during active gameplay.
